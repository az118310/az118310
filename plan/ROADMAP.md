## 一、残酷的现实（先看这段，再看计划）

### 1. 你不投的岗位
- ❌ **大模型算法工程师**（微调/预训练/论文）——JD 普遍要求硕士 + 论文 + 训练经验，投了就是浪费
- ❌ **大厂 AI 岗**——简历筛选阶段直接卡学历，连面试机会都没有
- ❌ **纯算法研究岗**——同上

### 2. 你要投的岗位（真实 JD 已验证接受大专）
搜索到的 2026 年实际在招岗位，明确写"大专"或"大专及以上"：

| 岗位 | 学历要求 | 核心要求 |
|---|---|---|
| AI Agent 开发工程师 | 大专 | Python 基础扎实、RAG、LangChain/LangGraph、工具调用、Agent 评测 |
| AI 应用开发工程师 | 大专 | LangChain/LlamaIndex、RAG 实战、Dify/扣子、Python Web 框架、部署运维 |
| AIAgent 应用开发工程师 | 大专+ | Prompt 工程、Function Calling、Agent、至少一个生产级项目 |

**这些岗位的共通要求（这就是你的学习大纲）**：
1. Python 熟练（数据结构、面向对象、工程规范）
2. LLM API 调用 + Prompt 工程
3. Function Calling / Tool Calling
4. RAG 检索增强生成
5. LangChain / LlamaIndex 框架
6. 至少一个**生产级**项目落地经验（能讲清架构取舍）
7. 部署运维（Linux / Docker / Nginx）

### 3. 大专能不能破局？能，但只有一条路
真实案例（专科 → 技术支持 → 夜学 RAG/LangChain → 把公司十年文档做成知识库产品 → 5 个 offer，最高 2 万）证明了一件事：

> **招聘方筛选的是"你能用 AI 产出真实工作吗"，不是"你哪个学校毕业的"。**

破局三件套：
- **一个代表作级项目**（胜过简历上堆 20 个技术名词）
- **可验证的产出**（GitHub 仓库 + 在线 Demo + 项目文档）
- **一个专业领域优势**（这���你有：真实电商客服业务 + 真实话术 SOP）

### 4. 你的隐藏优势（别浪费）
你是淘宝售前客服。这意味着：
- 你有**真实电商客服语料**和**真实 SOP 经验**——这是 RAG 训练/评测的天然素材
- 你懂**真实用户的提问方式**（比价、催发货、质疑质量）——这是意图识别最好的语料
- 面试时"淘宝客服 → AI 客服"是**极强的叙事**，不是转行，是升级

**所以你的代表作项目就做这个：把淘宝售前客服做成一���可上线的 AI 客服 Agent。**

## 六、求职期（2027/01/01 - 01/20）

**不是"学完再投"，是"边投边学"**——投出第一份简历到拿 offer 平均 2-3 个月。

- **投递节奏**：每周 8-12 家，分两批
  - 第一批（12/30 起）：门槛匹配的公司，用来练手、攒面试经验
  - 第二批（面试攒够 3-5 次后）：目标公司
- **目标公司类型**（大专友好的地方）：
  - 电商 SaaS / 客服系统厂商（Coze/Dify 生态集成商）← **你的主场**
  - 中小型 AI 应用公司（20-99人）
  - 传统软件公司的 AI 创新部门
  - 垂直行业 AI（教育、医疗、法律、政务）
  - **外包/人力派遣岗**（门槛最低，是绝佳跳板，别觉得丢人）
- **避雷**：凡是要你交培训费、押金、"AI 培训"后就承诺高薪的，一律不投
- **每周固定**：更新 GitHub（哪怕只提交笔记）、复盘面试、针对 bad case 补课

## 八、最可能让你失败的三件事（提前防）

| 风险 | 症状 | 对策 |
|---|---|---|
| **教程收藏癖** | 收藏了 20 个课程，一个没学完 | 每次学完必须产出可运行代码，否则不算学 |
| **只学不写** | 懂原理但写不出项目 | 每个知识点必须当天落到代码里 |
| **完美主义** | 项目做到 80% 一直打磨，不上线 | 设死线：12/13 必须有能跑的 v1，12/20 必须有在线 URL |

**再加一条：连续两天没学就立刻降级，不要硬撑。** 连续三天没学，先把目标降到"读文档"，找回节奏再上难度。断更一次不可怕，断更两周就完了。
